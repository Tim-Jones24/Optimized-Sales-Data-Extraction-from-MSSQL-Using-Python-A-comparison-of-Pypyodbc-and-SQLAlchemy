# Optimized Sales Data Extraction from MSSQL Using Python: A comparison of Pypyodbc and SQLAlchemy
This project explores the process of extracting sales data from an MSSQL database using Python. Two libraries, PypyOdbc and SQLAlchemy were compared to determine the most efficient and seamless approach.

### Overview
This project demonstrates a practical approach in extracting sales data from an MSSQL database using Python. it compares the performance and usability of two popular libraries:
1. **Pypyodbc**
2. **SQLAlchemy**
The goal is to identify the optimal library for seamless data extraction. Based on the comparison, SQLAlchemy emerges as the better option, offering better integration, flexibility and overall efficiency.

#### Tools and Libraries
* Python
* MSSQL Database
* PypyOdbc Library
* SQL Alchemy

#### Key Insights
* **Pypyodbc**: Straightforward but lacks flexibility for complex queries and large-scale applications.
* **SQLAlchemy**: Highly efficient with ORM capablities, making it ideal for scalable and maintable solutions.

#### Conclusion
SQLAlchemy proves to be better choice for extracting and handling sales data seamlessly from MSSQL databases.
